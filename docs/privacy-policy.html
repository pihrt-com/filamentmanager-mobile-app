Filament Manager Privacy Policy

Effective date: August 26, 2026

Filament Manager is an offline Android application developed by Martin Pihrt. This policy explains how the application handles information.

Information collection and sharing

Filament Manager does not collect, transmit, sell, or share personal information, device information, usage data, diagnostics, or advertising identifiers. The application contains no advertising, analytics, user accounts, or cloud service and does not request internet access.

Local application data

Printer names and filament details entered by the user are stored only in the application's private local database on the user's device. This data is used solely to provide the application's inventory functions and is removed by Android when the application data is cleared or the application is uninstalled.

Backup and sharing

The application can create a database backup when the user explicitly selects Export. Android's standard share interface then lets the user choose whether and where to send that file. Filament Manager does not select a recipient, upload the backup, or receive a copy. The privacy practices of the destination selected by the user are governed by that destination's own policy.

Children

The application is a workshop inventory utility and is not directed to children. It does not knowingly collect information from children or any other users.

Changes to this policy

If the application's data practices change, this policy and the Google Play Data safety declaration will be updated before the changed version is distributed.
